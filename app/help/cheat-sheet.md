Type the short name (the alias) and press Enter, or click the tool. Esc cancels. Enter on an empty line repeats the last command.

**Print it:** [cheat-sheet.pdf](https://getcadcraft.com/assets/apps/cadcraft/current/cheat-sheet.pdf) (one A4 page; on Letter paper print it with "fit to page").

## Draw

| Type | Command | What it does |
|---|---|---|
| `L` | {{cmd:LINE}} | Draw straight lines |
| `PL` | {{cmd:PLINE}} | Draw a connected line and arc chain |
| `C` | {{cmd:CIRCLE}} | Draw a circle (centre and radius) |
| `A` | {{cmd:ARC}} | Draw an arc |
| `REC` | {{cmd:RECTANG}} | Draw a rectangle from two corners |
| `POL` | {{cmd:POLYGON}} | Draw a regular polygon |
| `EL` | {{cmd:ELLIPSE}} | Draw an ellipse |
| `DT` | {{cmd:TEXT}} | Write one line of text |
| `T` | {{cmd:MTEXT}} | Write text that wraps (paragraph) |
| `H` | {{cmd:HATCH}} | Fill an area with a pattern |

## Modify

| Type | Command | What it does |
|---|---|---|
| `M` | {{cmd:MOVE}} | Move objects |
| `CO` | {{cmd:COPY}} | Copy objects |
| `RO` | {{cmd:ROTATE}} | Turn objects round a point |
| `SC` | {{cmd:SCALE}} | Make objects bigger or smaller |
| `MI` | {{cmd:MIRROR}} | Flip objects across a line |
| `O` | {{cmd:OFFSET}} | Draw a parallel copy at a distance |
| `TR` | {{cmd:TRIM}} | Cut objects back to where others cross them |
| `EX` | {{cmd:EXTEND}} | Lengthen objects up to others |
| `F` | {{cmd:FILLET}} | Round a corner with an arc |
| `CHA` | {{cmd:CHAMFER}} | Cut a corner with a straight edge |
| `E` | {{cmd:ERASE}} | Delete objects |
| `X` | {{cmd:EXPLODE}} | Break a block or polyline into its parts |
| `S` | {{cmd:STRETCH}} | Move the ends inside a crossing window |
| `AR` | {{cmd:ARRAY}} | Copy in a grid or a circle |
| `J` | {{cmd:JOIN}} | Join lines and arcs into one object |
| `BR` | {{cmd:BREAK}} | Cut an object in two, or take a piece out |

## Dimension

| Type | Command | What it does |
|---|---|---|
| `DLI` | {{cmd:DIMLINEAR}} | Dimension horizontally or vertically |
| `DAL` | {{cmd:DIMALIGNED}} | Dimension along a slanted line |
| `DRA` | {{cmd:DIMRADIUS}} | Dimension a radius |
| `DAN` | {{cmd:DIMANGULAR}} | Dimension an angle |

## Blocks and layers

| Type | Command | What it does |
|---|---|---|
| `B` | {{cmd:BLOCK}} | Make a block from objects |
| `I` | {{cmd:INSERT}} | Place a block |
| `LA` | {{cmd:LAYER}} | Open the layers |

## View and inquire

| Type | Command | What it does |
|---|---|---|
| `Z` | {{cmd:ZOOM}} | Zoom in, out or to everything (E) |
| `DI` | {{cmd:DIST}} | Measure a distance and an angle |
| `LI` | {{cmd:LIST}} | Show an object's details |
| `MA` | {{cmd:MATCHPROP}} | Copy one object's look onto others |

## File

| Type | Command | What it does |
|---|---|---|
| `U` | {{cmd:UNDO}} | Take back the last command |
| `SAVE` | {{cmd:SAVE}} | Save the drawing |
| `PLOT` | {{cmd:PLOT}} | Plot to PDF |

## Keys

Ctrl (Cmd on a Mac): Z undo · Y redo · S save · P plot.  F3 object snap · F8 ortho · F10 polar.  Space or Enter repeats the last command · the wheel zooms · dragging the wheel pans

New to drafting? Type `TOUR` for a guided first drawing, read [Getting started](topic:getting-started), or see every command in [Commands](topic:commands). Coming from other drafting software: [Coming from other drafting software](topic:coming-from) and the [command map](topic:command-map).
